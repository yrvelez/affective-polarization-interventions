# Testing 33 Student-Designed Interventions to Reduce Affective Polarization

Yamil Velez. Online survey experiment (Columbia IRB AAAU3946) testing 33 interventions designed by
students in an Experimental Design course against a control, among partisans.

No single intervention reliably reduced affective polarization or support for undemocratic practices
(two-sided tests); pooled across arms, polarization fell about 1 point on a 0–100 scale.

**Read the report: [report.md](report.md).**

- No pre-registration exists. The analysis plan in `pap.md` was reconstructed after data collection from
  the original analysis script; every test is post hoc.
- The report was generated by the [filedrawer](https://github.com/yrvelez/filedrawer) pipeline with no
  human review recorded (see the provenance badge).
- **Respondent-level data are not included in this repository.** Result tables (`results/`), figures,
  analysis scripts, the survey file and the codebook are. The scripts expect `data/raw_tidy.csv`; contact
  the author for data access.
