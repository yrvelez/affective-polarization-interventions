# Testing 33 Student-Designed Interventions to Reduce Affective Polarization

Yamil Velez. Adaptive online survey experiment (Lucid Theorem, November 9–25, 2022; Columbia IRB
AAAU3946) testing 33 interventions designed by students in a Fall 2022 Experimental Design course against a
pure control, among partisans. Interventions include videos (e.g. a perception-gap video, a Brené Brown
empathy video), articles (e.g. a meta-dehumanization correction, bipartisan legislation examples), images
and interactive quizzes; the report lists each one.

One intervention, a perception-gap video, significantly reduced affective polarization (−2.33 points on the
0–100 thermometer gap, p = .019, uncorrected across 32 arms); pooled across arms, polarization fell 0.82
points. No intervention changed support for undemocratic practices. Results match the published analysis
(N = 3,825).

**Read the report: [report.md](report.md).**

- Pre-registered on OSF (https://osf.io/k2nwj, DOI 10.17605/OSF.IO/K2NWJ, 2022-11-15). `pap.md` transcribes
  the registration; the registered tests are each intervention against control on affective polarization and
  on support for undemocratic practices, adjusting for both pre-treatment measures, with the registered
  exclusions (pure independents, the attention screener). The registration states no directional hypotheses.
- Carried out in collaboration with Hayley Cohen (see `ACKNOWLEDGMENTS.md`).
- The report was generated by the [filedrawer](https://github.com/yrvelez/filedrawer) pipeline with no
  human review recorded (see the provenance badge).
- De-identified respondent-level data are included: `data/raw_tidy.csv` (6,086 rows, before exclusions)
  and `data/clean.csv` (4,547 analysed respondents). Identifier and free-text columns were removed before
  any model saw the data; `codebook.md` describes every column.
